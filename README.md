# Open3D Nodes

一个基于浏览器的 3D 节点式建模与 AI 辅助工具。你可以通过节点组织几何操作，在视口中检查模型，并导入、导出模型文件。项目使用 React、Three.js、React Flow 和 Vite。

> 项目仍在开发中，欢迎通过 GitHub Issues 提交问题和建议，也欢迎提交 Pull Request。

## 功能概览

- 节点式几何工作流，包含基础形体、变换、布尔、阵列、旋转成形等节点
- 3D 视口、模型导入和导出，以及项目文件处理
- AI 辅助功能，可配置兼容 OpenAI 的云端服务或本地推理提供方
- 内置示例模板与操作记录

具体功能以当前代码为准，界面和节点可能持续变化。

## 本地运行

需要安装 Node.js（建议使用当前长期支持版本）。在项目目录打开终端后运行：

```bash
npm ci
npm run dev
```

开发服务器启动后，终端会显示本地访问地址。构建静态文件：

```bash
npm run build
npm run preview
```

## 本地大模型

本仓库不包含模型权重。模型文件体积较大，且其许可条款需要由使用者自行确认。

如需使用本地模型，请先阅读 `public/models/README.md`，从模型发布方获取模型并放到该目录，再在应用的 AI 设置中选择对应模型。不要把模型权重、API 密钥或个人数据提交到 GitHub。

## 数据与隐私

- AI 配置、API Key、工作内容和历史记录会保存在浏览器本地存储中。清理浏览器站点数据会清除这些内容。
- 选择云端 AI 服务时，发送给 AI 的提示词、上下文或图片会传到所选服务商；请先阅读服务商的隐私政策。
- 不要在公开电脑上保存真实 API Key。该应用的 API Key 设置保存在浏览器中，并非安全的密钥保管库。
- 本项目没有配置服务器端账号系统或协作后端；GitHub 协作是通过 Issues 和 Pull Requests 进行。
